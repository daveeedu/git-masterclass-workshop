# Contributing

This is a teaching repository, but we treat it like a real one:

1. Never commit directly to `main` — it's protected. Always work on a branch.
2. Open a Pull Request for every change, however small.
3. Request review from at least one other participant.
4. Keep commit messages descriptive: `"Fix navbar spacing on mobile"`, not `"update"`.
5. If your PR conflicts with `main`, that's not a mistake — resolve it and treat it as practice.

See the main [README](../README.md) for branch naming conventions.
